# Chamath Herath Portfolio

This workspace contains a single-page portfolio website built with semantic HTML, modern CSS, and vanilla JavaScript.

## Open

Open `index.html` in a browser.

## Notes

- The design includes sticky navigation, theme switching, animated counters, scroll reveals, a typing effect, contact form mailto handling, and an interactive Kandy map embed.
- The hero image is wired to use `profile.jpg` if you add one later, with a polished SVG fallback already included.
- React/Tailwind could not be scaffolded here because Node.js and npm are not available in this environment.
